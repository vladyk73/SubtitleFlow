# SubtitleFlow

Відкритий український інструмент для роботи з субтитрами `.srt`.

Поточна версія вміє:

- читати SRT-файли без завантаження їх на сервер;
- зберігати нумерацію та таймкоди;
- показувати репліки для ручного редагування;
- завантажувати результат як `.uk.srt`.

AI-переклад буде підключений через окремий захищений backend. API-ключ не можна зберігати в публічному GitHub-репозиторії або браузерному JavaScript.
